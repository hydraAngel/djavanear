# 🎵 Djavanear

**Djavanear** é um app interativo que celebra a obra poética de Djavan.  
Você pode gerar versos aleatórios, testar se reconhece de qual música vêm, e explorar cada álbum visualmente.

---

## ✨ Funcionalidades

- Geração de versos aleatórios
- Jogo: adivinhe a música
- Pontuação persistente
- Dica visual (imagem do álbum)
- Tema dinâmico por álbum (com base em cores da capa)
- Tema claro/escuro
- Responsividade total
- Animações suaves com framer-motion
- Página institucional com homenagem e créditos

---

## 📦 Tecnologias

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [Framer Motion](https://www.framer.com/motion/)
- [JSON](https://www.json.org/) para base de letras
- CSS Variables para temas visuais
- [Color Thief (via Python)](https://github.com/fengsp/color-thief) para extração de cores das capas
